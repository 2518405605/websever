# Milvus MCP RAG Agent

## 1. 项目简介

本项目是一个面向企业内容检索场景的 AI 搜索 Agent 实践项目，围绕 **内容采集、向量化存储、混合检索、MCP 工具封装与 Agent 调用** 构建完整流程。

项目以微信公众号文章等非结构化文本内容为数据来源，使用 N8N 实现自动化内容采集，使用 Milvus 构建向量知识库，并将检索能力封装为 MCP Server，使大模型 Agent 能够通过标准工具接口完成语义搜索、关键词检索、条件过滤和混合搜索等任务。

传统的 RAG 应用通常只关注“知识库 + 向量检索 + 大模型回答”的基础流程，但在真实企业业务场景中，用户查询往往不仅包含语义搜索需求，还会包含发布时间、发布者、返回数量、字段筛选等结构化约束条件。例如：

```text
搜索关于 AI 智能体相关的文章，文章发布时间在 2025.09.05 之前，
发布者是新智元，返回 3 篇文章，并给出文章标题、链接和发布者。
